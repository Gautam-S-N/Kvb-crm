# Project Transfer & Hosting Guide

This guide will help you move the **KVB-CRM** project to a new laptop and prepare it for hosting.

## 1. Files Prepared for Transfer
- **Database Dump**: `kvb_crm_backup.sql` (Located in the project root).
- **Environment Template**: `backend/.env.example`.

---

## 2. Moving to a New Laptop

### Step A: Database Setup
1. Install **MySQL Server** on the new laptop.
2. Open your MySQL terminal or a tool like MySQL Workbench.
3. Create a new database:
   ```sql
   CREATE DATABASE kvb_crm;
   ```
4. Import the backup file:
   ```bash
   mysql -u your_username -p kvb_crm < kvb_crm_backup.sql
   ```

### Step B: Project Setup
1. Copy the entire project folder to the new laptop.
2. Navigate to the `backend` folder and create a `.env` file from the example:
   - Copy `backend/.env.example` to `backend/.env`.
   - Update `DATABASE_URL` with your new MySQL credentials.
3. Install dependencies in both folders:
   ```bash
   # In /backend
   npm install
   npx prisma generate

   # In /frontend
   npm install
   ```
4. Run the project:
   - Backend: `npm start` (or `npm run dev`)
   - Frontend: `npm run dev`

---

## 3. Hosting Preparation

To host this application (e.g., on a VPS like DigitalOcean, AWS, or Render), follow these steps:

### Backend Hosting
1. **Database**: Use a managed MySQL service or install MySQL on your server.
2. **Environment Variables**: Set the production `.env` variables on your hosting provider.
3. **Build & Start**:
   ```bash
   cd backend
   npm install
   npx prisma generate
   # Use a process manager like PM2 to keep it running
   pm2 start src/index.js --name "kvb-crm-backend"
   ```

### Frontend Hosting
1. Update the `VITE_API_URL` (if applicable) in your frontend to point to your hosted backend.
2. Build the frontend:
   ```bash
   cd frontend
   npm run build
   ```
3. Deploy the resulting `dist` folder to a static hosting service (Netlify, Vercel, or Nginx on your VPS).

### Security Checklist
- [ ] Change `JWT_SECRET` in `.env`.
- [ ] Ensure the MySQL port (3306) is not publicly accessible (use `localhost` or a private network).
- [ ] Set up an SSL certificate (HTTPS) for both frontend and backend.
